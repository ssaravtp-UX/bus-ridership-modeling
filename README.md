# Bus Ridership Modeling

This project investigates bus ridership patterns using land-use subtypes and stop-level accessibility variables in Fredericton, Canada.

## Methods
- GIS-based 600 m buffer analysis
- Land-use subtype extraction
- Feature engineering in Python
- Machine learning models:
  - Linear Regression
  - Ridge Regression
  - Gradient Boosting
  - Random Forest

## Key Findings
- Random Forest achieved the best predictive performance
- Shelter availability and pedestrian accessibility were strong predictors of ridership
- Land-use subtype disaggregation improved interpretability of transit demand patterns

## Tools
- Python
- QGIS
- scikit-learn
